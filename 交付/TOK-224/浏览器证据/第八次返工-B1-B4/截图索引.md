## 不翻译的可见内容

- `Review Agent`：隔离浏览器夹具中的智能体名称；属于测试业务数据。
- `Board` 与 `BO`：隔离测试组织/账号显示名与其缩写；属于测试业务数据。
- `B2 UI activity evidence`、`TOKAAAAA-1`：测试任务标题与任务编号；属于用户内容/技术标识。
- `Local browser display test data.`、`Synthetic browser rendering evidence.`、`Synthetic terminal run response.`：由浏览器夹具提供的评论正文；属于用户内容，保留原文以证明评论数据不被 UI 文案翻译。
- `Codex`、`GitHub`、`Asana`、`Vercel`、`Paperclip`、`OAuth`：产品、服务、供应商或标准名。
- `environment.lease_acquired`：审计事件原始 action key，保留供机器检索；同一记录面向操作者的动作标签已翻译为“已获取环境租约”。实体机器值 `agent` 也保留，页面显示映射为“智能体”。
- `API`、`ID`、`URL`、`YYYY-MM-DD`：通用技术缩写或标准日期格式，不是待翻译句子。

B3 system notice 的样本文字由前端在显示层本地化。服务端 notice 来源仍由 TOK-226 并行席核对，本席没有改动服务端文件。各记录列出测试接口响应夹具；预期注入错误不当作浏览器脚本异常或生产服务端验收。
