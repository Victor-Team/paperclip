# 第5批语言切换浏览器取证报告

日期：2026-09-24  
实例：隔离 worktree `http://127.0.0.1:3200`（`feat/anc-zh-cn`）  
视口：1440 × 900，Chromium headless（`/usr/bin/google-chrome`）

## 已验证流程

1. 新浏览器上下文打开 `/search/dashboard`：`document.documentElement.lang` 为 `en`，`localStorage.paperclip.locale` 为空，页面显示英文“Tasks”。
2. 打开英文账号菜单，语言选择器提供 `English` 与 `简体中文` 两项；选择 `zh-CN` 后未导航，`html[lang]` 立即变为 `zh-CN`，本地存储写入 `zh-CN`，页面显示“任务”。
3. 刷新相同 URL：`html[lang]` 和本地存储仍为 `zh-CN`，页面仍显示“任务”。
4. 打开中文账号菜单，切回 `en` 并刷新：`html[lang]` 与本地存储均为 `en`，页面显示英文“Tasks”。
