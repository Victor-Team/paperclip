# TOK-241 production 外壳复现与本轮改动

## 结果摘要

在隔离 worktree 的 Vite `127.0.0.1:5176`、本地只读 Paperclip API `127.0.0.1:3100` 和独立 Chrome profile（CDP `127.0.0.1:9333`）中复现了两条现存渲染分支。生产 API 的 `GET /api/instance/settings/experimental` 返回 HTTP 200，当前记录为 `enableStreamlinedUi=true`、`enableStreamlinedLeftNavigation=true`。我没有写线上设置、业务数据或其它 worktree。

- 开关响应保持真实 `true` 时，`App.tsx` 使用 `Layout`，`/agents/:id/:tab` 渲染 `AgentDetail`；浏览器请求到 `AgentContextualSidebar.tsx`、`AgentConfigForm.tsx`、`RuntimeTestCard.tsx`。这与董事会图1的分组二级侧栏和运行环境表单结构相符。
- 要复现董事会图3的 legacy 外壳，我只在本地 Chrome 用 CDP `Fetch` 拦截 `127.0.0.1:5176/api/instance/settings/experimental` 的响应，将两个外壳字段临时回成 `false`；未改 API 服务端。`App.tsx` 该分支选择 `ProductionLayout`，`/agents/all` 选择 `ProductionAgents`，实际请求了 `src/pages/Agents.production.tsx`。树形 `OrgNode` 列表、大写页头和页签均出现。代码依据：`App.tsx:744,792,835` 和 `App.tsx:276-280`。
- `/decisions` 在 `App.tsx:420` 固定渲染 `WhatNeedsMe`，外壳仍由 `Layout`/`ProductionLayout` 分支决定。用本地 `false` 响应可以复现图4的 legacy 全局导航外壳；用真实 `true` 也复用同一决策页面组件。CEO 概览同样由 `AgentDetail` 渲染、外壳按设置切换；图2董事会附件没有周边导航，构图是概览内容区裁切。本轮同时保存了带 legacy 外壳的完整本地浏览器截图供比较。

## 线上 `true` 与原图3 legacy 外壳的差异

现在读取到的 API 值是 `true`；真实 `true` 分支在本地浏览器呈现 streamlined Agents 列表，不是图3树形页。仅用本地浏览器响应覆盖为 `false`，能通过正式 `App.tsx` 条件分支加载 production 树页。因此生产树并非通过换主题仿造。董事会原图没有同一时刻的开关接口响应、浏览器网络记录或构建版本信息，无法证明当时 `true` 如何同时对应图3 production 页面。现有证据支持“截图拍摄时的设置/构建与当前状态不同”，但不能确定具体历史原因；该差异保留为未解释的历史证据，不写成已证实原因。

董事会图3文件为 661×1008；隔离 Chrome 在 661 CSS px 会进入响应式列表/底部导航。为了核对并清楚读取 OrgTreeNode 与标签，本地 production 树截图使用 1440×1008 CSS px，维持 desktop 树外壳。原图尺寸可能经过缩放，但无原始 viewport 元数据，故此判断也不作确定结论。

## 本轮生产分支修复

仅修改授权的 `ui/src/pages/Agents.production.tsx`：

- `setBreadcrumbs` 从硬编码 `Agents` 改为现有 `sidebaragents.general.labelAgents` 键，页头不再渲染 `AGENTS`。
- production 页签改用与现有语言包同构的键：`agents.general.all`、`common.status.active`、`common.status.paused`、`agents.general.error`、`agents.general.builtIn`。
- 两处 OrgTreeNode/智能体行角色显示复用授权的 `agentRoleDisplayLabel`，读取已有角色键；不增加 locale 键、不改接口枚举/业务数据。

改后浏览器重载后页头为“智能体”，页签为“全部/活跃/已暂停/错误/内置”；树形结构仍在，角色显示为“项目经理/通用/研究员/质量保障”。UI typecheck 在本轮代码修改后重新通过（`pnpm --filter @paperclipai/ui typecheck`，退出码 0）；`git diff --check` 通过。对照表按董事会原文正向/反向各核 43/43，遗漏与额外项均为 0。40 个语言文件没有在本轮变更，沿用上轮已验证键形同构结果。
